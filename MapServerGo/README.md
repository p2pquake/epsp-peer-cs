# MapServerGo

`CLI map server` (C#) と同じ API を持つ地図生成サーバーの Go 実装です。
Cloud Run などで最小インスタンス数 0 のまま運用しても、コールドスタート直後から高速に応答することを目的としています。

## 使い方

```sh
cd MapServerGo
go run . -port 17101            # リソースは ../Map/Resources を自動で使います
```

| オプション | 説明 |
|---|---|
| `-port` | 待ち受けポート。省略時は環境変数 `PORT`、それもなければ `17101` |
| `-resources` | `Map/Resources` 相当のディレクトリ。省略時は環境変数 `MAP_RESOURCES`、実行ファイルと同じ場所の `Resources`、`../Map/Resources` の順に探します |
| `-preload` | 起動時に読み込んでおく地図 (例: `JAPAN_1024,JAPAN_4096`)。既定は初回利用時に読み込み |

エンドポイントとリクエスト形式は `CLI/Command/ServerSubCommand.cs` と同じです。

| パス | 内容 |
|---|---|
| `/test` | ヘルスチェック (`OK`) |
| `/earthquake` | 地震情報 (震度・震源) |
| `/tsunami` | 津波予報 |
| `/eew` | 緊急地震速報 (警報) |
| `/userquake` | 地震感知情報 |

## Docker / Cloud Run

リポジトリのルートをビルドコンテキストにします。

```sh
docker build -f MapServerGo/Dockerfile -t mapserver-go .
docker run -p 8080:8080 -e PORT=8080 mapserver-go
```

イメージは distroless (static) ベースで約 20MB です。Cloud Run が設定する `PORT` で待ち受け、SIGTERM で終了します。

## C# 版との違い

- 描画結果: トリム範囲 (出力画像のサイズ) は C# 版と同じ計算です (`go test` で確認)。
  アンチエイリアスや縮小の実装が異なるため、ピクセル単位では完全には一致しません (平均差 0.4/255 以下)。
- 線の描画 (津波予報の海岸線、緊急地震速報・地震感知情報の輪郭線、震源の × 印) は継ぎ目を丸めています。
- C# 版では例外になる一部の入力 (アイコンのない震度など) は、その地点を描画せずに続行します。
- ピア分布図 (フォントを使う描画) は地図サーバーから使われていないため移植していません。
- C# 版は描画後に地図全体から切り抜きますが、Go 版は切り抜く範囲だけを描画します (結果は同じ)。

## 性能 (参考)

千葉県東方沖の地震 (2026/08/30、199 地点) を使い、プロセス起動から JAPAN_1024 と JAPAN_4096 の地震情報を
順に生成し終えるまでの時間 (各 30 回の中央値、CPU 1 コアに制限)。

| 実装 | 起動〜両方生成完了 | 2 回目以降の JAPAN_4096 |
|---|---|---|
| C# (.NET 6, `CLI map server`) | 1158 ms | 220 ms |
| C# (.NET 8) | 1129 ms | 175 ms |
| Go (この実装) | 141 ms | 30 ms |
